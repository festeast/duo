# 🐱 Дуо

Жұбайыңмен бірге **түрік тілін** үйренуге арналған ретро-ойын стиліндегі қосымша.
Интерфейсі қазақ тілінде, аватарлары пиксель мысықтар.

## Мүмкіндіктер (1-кезең)

- 6 бөлім, 11 сабақ: Сәлемдесу, Отбасы, Мысықтар, Тамақ, Сандар, Махаббат
- Тапсырма түрлері: аударма таңдау, жұп табу, тыңдау (iPhone-дағы түрік дауысы), сөйлем құрастыру
- Қате жауап берілген тапсырма сабақтың соңында қайта шығады
- XP, деңгейлер (Марғау → Мысық патша), тиындар
- Пиксель мысық: жүн мен көз түсі, дүкендегі аксессуарлар (фес, тәж, көзілдірік, шарф…)
- Дуо: екі ойыншы, ортақ 🔥 стрик, апталық XP жарысы
- 8-bit дыбыстар (WebAudio арқылы, файлсыз)
- PWA: iPhone-да «Басты экранға қосу» арқылы нағыз қосымша сияқты ашылады, офлайн да жұмыс істейді

## Іске қосу

```bash
npm install
npm run dev
```

## Жоба құрылымы

```
src/
├── i18n/kk.ts        # интерфейстің барлық қазақша мәтіндері
├── data/course.ts    # түрік тілі сабақтары (жаңа сабақ осында қосылады)
├── data/cat.ts       # пиксель мысық пен аксессуар спрайттары
├── lib/store.ts      # прогресс, XP, стрик (қазір localStorage)
├── lib/exercises.ts  # сабақтан тапсырмалар генерациялау
├── lib/sound.ts      # 8-bit дыбыстар
├── lib/speech.ts     # түрікше айтылым
├── components/       # PixelCat, Hud
└── screens/          # Title, Setup, Home, Lesson, Result, Duo, Shop
```
