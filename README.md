# 🐱 Дуо

Жұбайыңмен (немесе достарыңмен) бірге **түрік тілін** үйренуге арналған ойын-қосымша.
Интерфейсі қазақ тілінде, аватарлары — сүйкімді мысықтар.

## Мүмкіндіктер

**📅 Бүгінге не бар?** (басты бет)
- Күн сайын ~10 сөз: алдымен қайталау керек сөздер (≤7), қалғаны — жаңа сөздер
- **Аралықпен қайталау**: дұрыс айтылған сөз 1 → 3 → 7 → 14 → 30 → 60 → 120 күннен кейін қайта келеді, қате болса — ертең
- Төменде үйренген сөздер тізімі: әр сөздің бекігені (●●●○○○○) және келесі қайталау уақыты
- Жаттығу түрлері: жаңа сөз карточкасы (сурет + мысал сөйлем), аударма таңдау, тыңдау, **өзің жаз** (ç ğ ı ö ş ü батырмаларымен), жұп табу, сөйлем құрастыру, **тыңда да қайтала** (микрофон)
- **🔗 Қазақшаға ұқсас сөздер** (su — су, göz — көз) және **⚠️ жалған достар** (dün — кеше, түн емес!)
- **💡 Бүгінгі кеңес**: түрік грамматикасы қазақшамен салыстырылады (-da/-de = -да/-де т.б.)
- Сөздер 18 тақырыптан алынады: 170+ сөз, 90+ сөйлем

**📖 Оқу**
- 5 қысқа әңгіме (оңай → қиын), кез келген сөзді бассаң — аудармасы, әр сөйлемді тыңдауға болады

**Бірге 💞**
- Достық код (`DUO-1234`) арқылы дос қосу, сұранысты қабылдау
- Әр доспен ортақ 🔥 стрик — екеуің де сабақ өткен күндер
- Досыңның бүгін оқығанын көру, апталық XP көшбасшылары
- **Рөлдік диалогтар** — 16 сахна, 3 деңгей, досыңды шақырасың, әрқайсың өз рөліңді ойнап, репликаңды түрікше құрастырасың — нақты уақытта:
  - Оңай: Танысу, Кафеде, Кешкі ас, Дүкенде, Таксиде, Қонақүйде, Кездесу
  - Орта: Дәрігерде, Білім, Мешітте, Мәдениет, Тарих
  - Қиын: Ғылым, Жұмыс сұхбаты, Экология, Әдебиет
  - Диалогтағы кейіпкерлердің аттары — ойыншылардың өз аттары (түрікшеде латынмен: Әділхан → Edilhan)
- Диалогта репликаны **дауыспен айтып** жауап беруге болады (🎤)
- Дос жоқ болса — мысықпен жаттығу

**Дауыс** — Профильде түрік дауысын және сөйлеу жылдамдығын таңдауға болады

**Мысық**
- Жүн мен көз түсі, дүкендегі аксессуарлар (фес, тәж, цилиндр, құлаққап, көзілдірік, шарф…)
- XP, деңгейлер (Марғау → Мысық патша), тиындар

## Технологиялар

React + TypeScript + Vite (PWA) · Supabase (Postgres, Auth, Realtime) · Vercel

## Supabase баптау (бір рет)

1. [supabase.com](https://supabase.com) → **New project** (тегін жоспар жеткілікті).
2. **SQL Editor** → `supabase/migrations/` ішіндегі файлдарды ретімен (алдымен `20261102…_init.sql`, сосын `20261103…_words.sql`) қойып, әрқайсысын **Run** бас.
3. **Authentication → Sign In / Providers → Email** → **Confirm email** опциясын өшір
   (әйтпесе тіркелгенде поштаны растау керек болады).
4. **Project Settings → API** бөлімінен `Project URL` мен `anon public` кілтін көшір.
5. **Vercel → Project → Settings → Environment Variables**:
   - `VITE_SUPABASE_URL` = Project URL
   - `VITE_SUPABASE_ANON_KEY` = anon кілті

   Сосын **Deployments → Redeploy**.

## Жергілікті іске қосу

```bash
npm install
npx supabase start        # Docker керек; жергілікті база
cp .env.example .env.local  # supabase start берген URL мен ANON_KEY-ді жаз
npm run dev
```
